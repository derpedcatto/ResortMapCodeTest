I keep my setup light, using the Claude Code desktop app with the “Context7” plugin (so Claude can fetch up-to-date documentation when needed), "Superpowers" (mainly for brainstorming and code-review skills) and "Modern Web Guidance" for some help in building client components. Sometimes I don't even generate code and use it as a searching tool only (for additional info, or to find something specific in docs). Before sending it to work on the task, I try to give as much context and task description as possible.

Here are my main use cases:

- Discussing code/solution/architectural ideas;
- Code review;
- Generating boilerplate code;
- Writing snippets of code that I could actually try and use (but always double-checking them, not blindly copying code);
- Writing docs/comments;

I always read the code it generates (I'm well aware that it can hallucinate even on simple tasks). Most of the time, I'm even copying/writing generated code by hand because I understand it better when I'm actually typing it all out instead of just copying and pasting (but yes, sometimes I do this too, usually with snippets that I'm pretty confident are fine).

This is pretty much it! I'm not into vibe-coding with parallel agents, I like to work with AI as pair-programming partner.
